🌙 Dream-Recorder (梦境记录与AI分析平台)

> A web-based dream recorder built with Vibe-coding (AI-assisted development).
> 这是一个基于 AI 辅助编程 (Vibe-coding) 独立开发的全栈 Web 应用，旨在帮助用户记录、追踪并利用大模型深度解析自己的梦境与潜意识状态。

💡 项目简介

梦境是潜意识的折射。本项目不仅仅是一个简单的备忘录，而是一个结合了**情绪可视化**与**大语言模型 (LLM) 分析**的个人精神状态追踪工具。在这个平台上，你可以随时记录光怪陆离的梦境，赋予它们情绪色彩，并通过 AI 的视角更深入地了解自己近期的心理状态。

 ✨ 核心功能

 **📝 灵活的梦境记录**
    支持随时随地记录梦境内容（支持文字与语音上传）。
    **时光倒流功能**：支持自由修改记录日期，即使是回忆起很久以前的梦，也能将其准确归档到属于它的那一天。
 **🎨 情绪色彩标记**
    为每一个梦境赋予专属的“情绪颜色”（如代表焦虑的深色，或代表愉悦的明亮色）。
 **📊 潜意识状态可视化**
 <img width="1524" height="1050" alt="image" src="https://github.com/user-attachments/assets/beab6d57-4ec8-41d0-b9eb-9cef1cb1a181" />
    **历史页面数据看板**：自动生成“周梦境色彩图”和“月梦境色彩图”。
    通过直观的色块分布，帮助用户一眼洞察自己近期的情绪波动和精神状态。
**🤖 AI 深度梦境解析 (核心亮点)**
<img width="2294" height="1464" alt="image" src="https://github.com/user-attachments/assets/a62872e6-38a1-44a7-88db-ea43b7b7257a" />

    后端接入大语言模型 (LLM)。
    对用户记录的每一个梦境进行个性化分析，从心理学和潜意识角度提供解读，帮助用户更好地觉察自我。

## 🛠️ 技术栈与开发方式

* **开发模式**：全程采用 **Vibe-coding (AI 辅助编程)** 模式进行开发，通过精准的 Prompt Engineering 快速实现从创意到全栈代码的落地。
* **后端支撑**：基于 Python 构建 Web 服务逻辑与 API 路由调度。
* **AI 接入**：集成大语言模型接口，实现自动化的文本处理与心理分析生成。
* **前端交互**：使用 HTML/CSS/JavaScript 结合模板引擎，实现响应式布局与色块图表渲染。

## 🚀 本地运行指南

1. 克隆本项目到本地：
   `git clone https://github.com/你的用户名/Dream-Recorder.git`
2. 进入项目目录并安装相关依赖（基于 Python 环境）。
3. 运行 `app.py` 启动本地服务器。
4. 在浏览器中访问 `http://127.0.0.1:5000` 即可开始记录你的梦境。
